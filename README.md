# ⚡ VoltForge

An interactive Electronics Engineering toolkit built using HTML, CSS, and JavaScript.

VoltForge is a beginner-friendly frontend engineering project featuring essential ECE utilities, calculators, and interactive tools designed to simplify core electronics concepts through a clean and modern interface.

---

## 🔥 Features

- ⚡ Ohm’s Law Calculator
- 🔋 Power Calculator
- 🎨 Interactive Resistor Color Code Decoder
- 🌙 Modern Dark UI
- 📱 Responsive Design
- ✨ Smooth Animations & Hover Effects
- 🧠 Beginner-Friendly Engineering Utilities

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
